FILE: app/page.tsx
================================================================================
TYPE: Main Next.js App Router Page (Home / Dashboard & Reader Screen)
PURPOSE:
The primary interactive single-page application (SPA) hub. It controls the lifecycle of the user session, orchestrates switching between the Landing/Upload/Library screen and the Split-Layout Reader Screen, loads saved books from both local storage and cloud, and integrates the audio engine.

WHAT IT ACTUALLY DOES:
1. Orchestrates Application State:
   - Manages the active PDF document (document), splash screen visibility (showSplash), mobile sidebar drawer state (isMobileOpen), and saved reading library (libraryBooks).
   - Integrates the core vocal narration hook (useVocalReader), passing the loaded document to initiate karaoke synchronization and audio speech synthesis.
2. Manages User Library & Cloud Synchronization:
   - Runs refreshLibrary() on mount and after document changes.
   - Merges local offline books stored in browser IndexedDB/localStorage (getLibraryMetadata) with books uploaded to the cloud fetched via /api/books for authenticated Clerk users.
   - Sorts the books chronologically based on lastReadAt.
3. Displays the Animated Splash Screen:
   - Presents SplashScreen on initial load and dismisses it after 2.2 seconds with smooth exit animations using Framer Motion.
4. Renders Conditional View States:
   - State A (No document loaded): Displays the Hero Banner, Android APK download link, PDFUploader (drag-and-drop file ingestion), LibraryGrid (recent books to resume or delete), and feature highlights (multi-column support, karaoke highlighting, TTS narration).
   - State B (Document loaded): Mounts the reading environment with SidebarControls on the left (or mobile drawer) and KaraokeDisplay in the center, wrapped in an ErrorBoundary for fault tolerance.
5. Book Resumption Logic:
   - When a user clicks a book from the library (handleResumeBook), it attempts to load full document data from local IndexedDB. If it is a cloud book not stored locally, it fetches the PDF file from the remote ImageKit URL, parses it via extractTextFromPDF, and resumes narration from the exact last read page, sentence, and word index.
6. Mobile-Optimized Floating Quick-Action Bar:
   - On mobile screens, renders a fixed bottom navigation pill with Rewind 10s, Play/Pause toggle, Fast-Forward 10s, and a drawer trigger button for reader controls.

FILE: app/api/books/route.ts
================================================================================
TYPE: Next.js API Route (GET /api/books)
PURPOSE:
Retrieves the list of saved PDF files uploaded to cloud storage by the currently authenticated user.

WHAT IT ACTUALLY DOES:
1. Authentication Verification:
   - Authenticates the incoming request using @clerk/nextjs/server's auth().
   - If the user is unauthenticated (!userId), returns an empty list ({ files: [] }).
2. Cloud Storage Query:
   - Instantiates an ImageKit server SDK client using secret environment variables (IMAGEKIT_PRIVATE_KEY, NEXT_PUBLIC_IMAGEKIT_PUBLIC_KEY, NEXT_PUBLIC_IMAGEKIT_URL_ENDPOINT).
   - Queries ImageKit for all PDF files residing in the user's isolated folder: /vocal_reader/${userId}/.
3. Response Serialization:
   - Returns a JSON response containing file objects with their names, file IDs, sizes, creation timestamps, and access URLs so the frontend can populate the cloud library.
   - Catches and logs storage errors safely without failing the client.

FILE: app/api/dictionary/route.ts
================================================================================
TYPE: Next.js API Route (POST & GET /api/dictionary)
PURPOSE:
Provides AI-powered English word definitions, Hindi translations, phonetic pronunciations, and bilingual example sentences using Google Gemini AI, and manages saved vocabulary in the database using Prisma.

WHAT IT ACTUALLY DOES:
1. POST Request (Word Definition & AI Lookup):
   - Accepts a JSON payload { word: "..." } and cleans the word string.
   - Calls Google Gemini 2.5 Flash API (gemini-2.5-flash:generateContent) with a strict JSON system prompt requiring 5 keys:
     * pronunciation: Phonetic spelling (e.g. /wɜːrd/)
     * hin: Direct Hindi translation
     * meaning: Short, clear English definition
     * exampleEng: English example sentence
     * exampleHin: Hindi translation of the example sentence
   - Sanitizes Gemini output by stripping any markdown backticks before JSON parsing.
   - Database Persistence (Prisma): If the user is authenticated via Clerk, executes an upsert on the SavedWord table keyed by compound unique index userId_word, storing or updating the definition and timestamp in PostgreSQL.
   - Returns the structured dictionary data as JSON to the client.
2. GET Request (User Vocabulary Retrieval):
   - Authenticates the user via Clerk (auth()).
   - If not logged in, returns a 401 Unauthorized response.
   - Queries Prisma database for all words saved by userId, sorted in reverse chronological order (createdAt: 'desc').
   - Returns { words: [...] } to feed the "My Vocabulary" drawer.

FILE: app/api/imagekit/auth/route.ts
================================================================================
TYPE: Next.js API Route (GET /api/imagekit/auth)
PURPOSE:
Generates client-side upload authentication parameters (token, expire timestamp, and cryptographic signature) required for direct browser-to-ImageKit file uploads.

WHAT IT ACTUALLY DOES:
1. Security Check:
   - Verifies the user is logged into Clerk before allowing cloud upload token generation. Returns 401 Unauthorized for anonymous requests.
2. Token Generation:
   - Uses the ImageKit SDK (imagekit.getAuthenticationParameters()) with server-side private keys to generate a short-lived signature, token, and expiration timestamp.
3. Client Handshake:
   - Returns JSON authentication parameters to PDFUploader.tsx, enabling secure, client-side direct uploads to ImageKit without proxying heavy 50MB PDF binaries through the Next.js server.

FILE: hooks/useVocalReader.ts
================================================================================
TYPE: Core Custom Hook / Audio & Reading Controller
PURPOSE:
The central engine controlling speech synthesis, karaoke word/sentence synchronization, speed pacing, keyboard shortcuts, and reading progress calculation.

WHAT IT ACTUALLY DOES:
1. Speech Synthesis Synchronization (TTS):
   - Initializes window.speechSynthesis and loads system voices.
   - Manages an utterance queue that reads sentences sequentially.
   - Uses speech boundary events (onboundary) to match spoken words to exact word indices for live karaoke highlighting.
2. Visual Speed Reading Fallback (TTS Disabled):
   - When voice is disabled, runs an interval timer based on the active WPM ((60 / wpm) * 1000) to highlight words at exact reading speed.
3. Live Position Controls:
   - Supports jumping to any page, sentence, or word.
   - Supports 10-second forward/backward time skipping.
4. Auto-Save Reading State:
   - Automatically writes current progress (page, sentence index, word index, and percentage) to IndexedDB and localStorage using debounced storage calls.
5. Keyboard Shortcuts:
   - Listens for Up and Down arrow keys to increase or decrease WPM on the fly.

FILE: lib/pdfParser.ts
================================================================================
TYPE: PDF Extraction & Column Detection Utility
PURPOSE:
Parses raw PDF binary files, detects multi-column layouts, and extracts clean, ordered text segmented into sentences.

WHAT IT ACTUALLY DOES:
1. Multi-Column Layout Detection:
   - Inspects the X and Y coordinates of text items on each page.
   - Detects two-column research paper structures by evaluating whitespace gutters between 45% and 55% of the page width.
   - Sorts text down column 1 first, then column 2, preventing the common bug where reading order jumps horizontally across columns.
2. Sentence Segmentation:
   - Splits continuous text into clean sentences using Intl.Segmenter where available, with a regex fallback handling sentence termination punctuation (., !, ?).
3. Standardized Output:
   - Returns a structured PDFDocumentData object containing pages, page numbers, full text, and sentence arrays.

FILE: lib/storage.ts
================================================================================
TYPE: Client-Side Offline Persistence Manager
PURPOSE:
Provides offline persistence for reading history and full PDF text using a hybrid IndexedDB and localStorage model.

WHAT IT ACTUALLY DOES:
1. IndexedDB (VocalReaderDB):
   - Stores full extracted document data (PDFDocumentData) so large documents can be reopened instantly offline without re-parsing.
2. LocalStorage (vocal_reader_library_metadata):
   - Stores lightweight metadata (name, page count, last read page, sentence, word, percentage, and timestamp) for fast library rendering.
3. CRUD Operations:
   - saveBookToLibrary: Upserts book metadata and full text.
   - loadBookFromLibrary: Retrieves full document data by book name.
   - removeBookFromLibrary: Deletes the book from both IndexedDB and localStorage.
