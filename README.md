# GoalBook_Servers

Monorepo containing services and applications for the GoalBook platform.

## Projects

- **AiPythonServer**: Python FastAPI service for AI processing, vector search, and book analysis.
- **GoalBook_DB**: Database configurations, migrations (Prisma/PostgreSQL), schemas, and replication setups.
- **GoalBook_MobileApp**: React Native / Expo mobile application.
- **GoalReader_web**: Next.js web application for book reading and AI interaction.
- **UserInteractionServer**: Node.js backend server handling user interactions and business logic.
